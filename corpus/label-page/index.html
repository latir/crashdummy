How this works (read once)

Review queue is the short path: about 115 required questions, then optional audits. Each card asks one thing, shows what the tool and the three models said, and takes y / n / u. Label tests is the full labelling view, if you want it.

For each test, tick every problem you see. A test you mark Reviewed with nothing ticked counts as "no problem" for every rule. Click a problem row once for yes, twice for unsure, three times to clear. Each row spells out what the problem means, so you do not need to look it up. Judge from the code alone. Each test shows the helpers it calls, so you rarely need to leave the card. Keys: j/k move, 1–9 cycle a problem, Enter marks reviewed and moves on. Full definitions are in corpus/LABELING.md.
